# Sahaara AI Welfare Platform - Website

## Overview

This is the official website for the **Sahaara AI Welfare Platform**, an AI-based predictive personnel stress and welfare monitoring system designed specifically for uniformed forces.

## Features

- **Responsive Design**: Fully responsive website that works on all devices
- **Modern UI/UX**: Clean, professional, and intuitive interface
- **Animation Effects**: Smooth animations and transitions
- **Mobile Navigation**: Hamburger menu for mobile devices
- **Contact Form**: Integrated contact form for inquiries
- **SEO Optimized**: Structured content for better search engine visibility

## Getting Started

### Prerequisites
- A modern web browser
- Basic knowledge of HTML, CSS, and JavaScript

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yuvrajgaikwad55/Sahaara-AI-Welfare-Platform-.git
```

2. Navigate to the website directory:
```bash
cd website
```

3. Open `index.html` in your web browser

### Running Locally

For best results, run the website using a local server:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server
```

Then navigate to `http://localhost:8000`
