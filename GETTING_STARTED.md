# SAATHI - Welfare Intelligence Platform
## Quick Start Guide

### 🚀 Start in 3 Steps

#### Step 1: Setup (one-time)
```bash
chmod +x start.sh
./start.sh
```

#### Step 2: Run
```bash
chmod +x run.sh
./run.sh
```

#### Step 3: Access
- 🌐 **Website**: http://localhost:3000
- 🔌 **API**: http://localhost:5000
- 🤖 **ML Engine**: http://localhost:8000
